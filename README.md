# JOB_Track (이직로그)

안드로이드에서 기업 분석과 이직 지원 현황을 관리하는 개인용 앱입니다.

## 주요 기능

- 지원 현황 대시보드
- 저장 기업 목록 및 검색
- 지원 예정 / 면접 상태 필터
- 기업별 상세 분석
- 기업 홈페이지 / 채용 페이지 링크
- 관심도 및 직무 적합도 관리
- 기업 추가 / 수정 / 삭제
- Android 공유 메뉴로 기업 분석 바로 저장
- JSON 직접 붙여넣기
- 클립보드에서 기업 분석 바로 가져오기
- `.json` 파일 가져오기 / 데이터 백업
- 안드로이드 시스템 뒤로가기 내비게이션
- 화면 크기에 맞춘 반응형 UI
- 서버 없이 WebView `localStorage`에 로컬 저장
- 앱 아이콘 적용
- 기본 샘플/복구용 기업 데이터 포함

## 빠른 저장 흐름

`ChatGPT 앱 저장용 JSON → 이직로그 → JSON 직접 붙여넣기 / 클립보드 / 파일 선택 → 자동 저장`

공유된 텍스트 안에 설명 문장이나 JSON 코드블록이 함께 있어도 JSON 객체를 찾아 저장하도록 처리합니다. 앱 저장용 JSON에는 `company` 필드가 필요합니다.

## 화면 흐름

`홈 → 저장 기업 → 기업 검색/목록 → 기업 선택 → 기업 분석 상세`

뒤로가기는 `상세 → 기업 목록 → 홈` 순서로 동작하며, 홈에서 뒤로가기를 누를 때만 앱이 종료됩니다.

## v1.9 변경 사항

- v1.6 기반 기능을 유지하면서 앱 버전을 v1.9로 갱신
- 기업 목록 진입 및 검색 기능 유지
- 데이터 관리 화면에 `JSON 직접 붙여넣기` 버튼 추가
- `클립보드에서 가져오기` / `JSON 파일 선택` / 백업 복사 기능 유지
- 노츠, 화이트큐브, 윈스테크넷, 토스증권, 코딧 등 기본 기업 데이터 포함
- 앱 상단에 v1.9 버전 표시
- 앱 아이콘 리소스 적용
- GitHub Actions에서 JavaScript 구문 검증 후 APK 빌드
- APK 내부의 `index.html`에 필수 기능 문자열이 실제 포함됐는지 검증
- APK 서명 검증 및 버전명 검증 추가
- 잘못된 구버전 소스가 빌드되는 회귀를 방지하도록 빌드 파이프라인 보강

## v1.6 변경 사항

- v1.5에서 JavaScript 구문 오류로 앱 전체 UI가 동작하지 않던 회귀 버그 수정
- 공유 저장 / 클립보드 가져오기 / JSON 파일 가져오기 기능 유지
- `+` 기업 추가, 기업 목록 검색, 상세 화면, 뒤로가기 기능 유지
- GitHub Actions 빌드 과정에 `node --check` JavaScript 구문 검증 추가

## v1.5 기능

- Android `ACTION_SEND`를 등록해 공유 메뉴에서 `이직로그`를 선택할 수 있도록 추가
- 공유된 텍스트에서 순수 JSON, JSON 코드블록, 설명이 섞인 JSON을 자동 인식
- 한 기업을 공유하면 저장 후 바로 해당 기업 상세 화면으로 이동
- 동일한 ID의 기업은 중복 생성하지 않고 기존 데이터 갱신
- 클립보드 가져오기 추가
- 기존 `.json` 파일 가져오기 기능 유지

## 기술 구성

- Android Java
- Android WebView
- HTML / CSS / JavaScript
- LocalStorage
- Android Sharesheet (`ACTION_SEND`)
- Android Clipboard Bridge
- GitHub Actions

## 빌드 및 검증

GitHub Actions에서 다음 순서로 APK를 빌드합니다.

1. 최신 JOB_Track 소스 가져오기
2. v1.4 → v1.5 → v1.6 → v1.9 패치 적용
3. `node --check`로 JavaScript 구문 검사
4. v1.9 필수 기능 문자열 확인
5. Android APK 빌드
6. APK 서명 검증
7. APK 내부 `assets/index.html` 재검사
