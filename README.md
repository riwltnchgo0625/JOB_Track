## 프로젝트 소개

이직로그(JobTrack)는 관심 기업을 단순히 저장하는 데서 끝나지 않고, **기업 분석 → 지원 판단 → 지원 진행 → 결과 기록**까지 한 흐름으로 관리하기 위해 만든 개인용 Android 앱입니다.

기업별 분석 내용, 직무 적합도, 관심도, 지원 상태를 기록할 수 있으며 데이터는 별도 서버 없이 휴대폰 내부에 저장됩니다. ChatGPT 등에서 정리한 기업 분석 결과를 JSON으로 가져와 바로 저장할 수 있고, 전체 데이터를 JSON으로 백업/복원할 수 있습니다.

## 주요 기능

### 홈 대시보드
- 저장 기업 수
- 진행 중 기업 수
- 서류 합격 수
- 최종 합격 수
- 상태 카드 터치 시 해당 기업 목록으로 이동

### 기업 목록
- 기업명 / 직무 / 산업 검색
- 지원 상태별 필터
- 저장 기업 목록 조회
- 기업 선택 후 상세 분석 화면 이동

### 기업 상세 분석
- 기업/직무 기본 정보
- 사업 구조 및 기업 분석
- 재무 정보
- 경쟁사
- 최근 이슈
- JD / 채용 키워드
- 지원동기 포인트
- 개인 메모

### 개인 평가 및 지원 관리
- 관심도
- 직무 적합도
- 지원 상태 관리
- 기업 추가 / 수정 / 삭제

### 데이터 가져오기 / 백업
- JSON 직접 붙여넣기
- 클립보드에서 가져오기
- JSON 파일 선택
- Android 공유 메뉴로 기업 분석 저장
- 전체 데이터 백업 / 복원

### Android 기능
- 시스템 뒤로가기 내비게이션
- 홈 화면 JT 위젯
- 반응형 모바일 UI
- 앱 아이콘 적용

## 빠른 저장 흐름

```text
ChatGPT에서 기업 분석
        ↓
앱 저장용 JSON 생성
        ↓
이직로그 설정
        ↓
직접 붙여넣기 / 클립보드 / JSON 파일 / 공유
        ↓
기업 데이터 자동 저장
```

공유된 텍스트 안에 설명 문장이나 JSON 코드블록이 함께 있어도 JSON 객체를 찾아 저장하도록 처리합니다. 앱 저장용 JSON에는 `company` 필드가 필요합니다.

## 화면 흐름

```text
홈
 ├─ 저장 기업 ─┐
 ├─ 진행 중   ├─→ 기업 목록 → 기업 상세 분석
 ├─ 서류합격  │
 └─ 최종합격 ─┘

홈
 ├─ + → 기업 추가 / 수정
 └─ 설정 → JSON 가져오기 / 백업 / 복원
```

뒤로가기는 기본적으로 `기업 상세 → 기업 목록 → 홈` 순서로 동작하며, 홈에서 뒤로가기를 누를 때 앱을 종료합니다.

## 데이터 저장

기업 분석 데이터는 앱 내부 `localStorage`에 저장됩니다.

별도 서버를 사용하지 않기 때문에 개인 데이터는 기본적으로 기기 내부에서 관리되지만, 앱 삭제 시 데이터가 사라질 수 있으므로 중요한 데이터는 설정 화면의 **JSON 백업** 기능을 사용하는 것을 권장합니다.

## 빌드

Android SDK 35와 Java 17 기준입니다.

```bash
gradle assembleRelease
```

GitHub Actions를 통해 서명된 Release APK를 자동 빌드하고 다음 항목을 검증합니다.

- APK 생성 여부
- APK 서명
- 패키지명
- 버전명
- 위젯 포함 여부
- `assets/index.html` 필수 기능 포함 여부
- JavaScript 구문 검사
