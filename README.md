# JOB_Track (이직로그)

안드로이드에서 기업 분석과 이직 지원 현황을 관리하는 개인용 앱입니다.

## 주요 기능

- 지원 현황 대시보드
- 저장 기업 목록 및 검색
- 지원 예정 / 면접 상태 필터
- 기업별 상세 분석
- 기업 홈페이지 / 채용 페이지 링크
- 관심도 및 직무 적합도 관리
- 기업 추가 / 수정 / 삭제
- ChatGPT에서 받은 `.json` 파일 직접 선택 후 기업 분석 저장
- JSON 데이터 백업
- 안드로이드 시스템 뒤로가기 내비게이션
- 화면 크기에 맞춘 반응형 UI
- 서버 없이 WebView `localStorage`에 로컬 저장

## 화면 흐름

`홈 → 저장 기업 → 기업 검색/목록 → 기업 선택 → 기업 분석 상세`

뒤로가기는 `상세 → 기업 목록 → 홈` 순서로 동작하며, 홈에서 뒤로가기를 누를 때만 앱이 종료됩니다.

## v1.4 변경 사항

- `+` 버튼을 누르면 기업 추가 화면이 정상적으로 열리도록 수정
- 기존 `form()` 전역 함수 충돌 가능성을 피하도록 기업 편집 함수를 `openForm()`으로 변경
- 설정 → 데이터 관리에서 `.json` 파일을 직접 선택해 가져올 수 있도록 변경
- Android WebView 파일 선택기 지원 추가
- 동일한 ID의 기업 JSON을 다시 가져오면 중복 추가 대신 기존 데이터를 갱신

## 기술 구성

- Android Java
- Android WebView
- HTML / CSS / JavaScript
- LocalStorage
- GitHub Actions

## 빌드

Android Studio에서 프로젝트를 열어 빌드할 수 있습니다.

GitHub Actions는 공개 저장소에 서명키를 올리지 않기 위해 `assembleDebug`로 APK를 빌드합니다. 실제 배포용 서명키와 비밀번호는 저장소에 포함하지 않습니다.
